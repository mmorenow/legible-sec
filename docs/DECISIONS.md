## B. Conflicts found between agents, and resolutions

1. **Benchmark frontier generator vs product model.** Agent 6 designed the judge panel (Gemini 3.1 Pro + Claude + DeepSeek V4) around GPT-5.5 as the A/B generator. Agent 4 picked claude-sonnet-5 as the product generator. Running the benchmark on a model the product doesn't use would break the "benchmark measures the product" story. **Resolution: A/B generator = claude-sonnet-5 (same as product); judge panel rotated per Agent 6's own disjointness rule to Gemini 3.1 Pro + GPT-5.5 + DeepSeek V4, median-aggregated.** Generators are then Anthropic (A/B) and Qwen (C0/C/D); no judge shares a family with any generator. Verified this session via the claude-api canonical reference: `claude-sonnet-5` $3/$15 (intro $2/$10 to 2026-08-31), `claude-haiku-4-5` $1/$5, `claude-opus-4-8` $5/$25.
2. **MiniCheck variant.** Agent 4 said MiniCheck-FT5 (770M); Agent 6 said Bespoke-MiniCheck-7B via Ollama. **Resolution: Bespoke-MiniCheck-7B (Ollama) primary — actively distributed, one-liner install, stronger; FT5 as CPU fallback.**
3. **Alignment embedder.** Agent 3 suggested all-mpnet-base-v2 "or current top MTEB"; Agent 4's verified pick is Qwen3-Embedding-0.6B. **Resolution: Qwen3-Embedding-0.6B everywhere** (its 70.70 Eng-v2 dominates mpnet; one model, one dependency).
4. **Corpus size assumptions.** Agent 2 costed 500–1,000 PDFs before Agent 1's counts existed. Agent 1's real inventory: 433 (TOB) + ~290 (ppr unique) + ~150 (Cure53) + ~80 (OSTIF non-TOB) ≈ **950 PDFs** + CISA HTML (no PDFs). Agent 2's midpoint (37,500 pages) stands; no re-costing needed.
5. **Product judge family overlap** (Haiku judges Claude output). Not flagged by Agent 4; Agent 6's self-preference literature makes it a concern. **Resolution: accepted for the product** (deterministic layer + MiniCheck cover the hallucination-blind-spot risk; product judge verifies claims rather than ranking systems) — but documented as a limitation, and the benchmark never uses same-family judging.

| D59 | The model layer is verified, not trusted | Every quote a model returns is anchored back into the text it named, by literal substring match with whitespace and case normalised.
